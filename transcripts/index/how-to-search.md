# Как искать по лекциям (инструкция для Claude)

Читать первым при любом вопросе по содержанию лекций курса «Философия и история науки» (7 лекций от ментора). Расшифровки целиком не перечитывать.

## Документы проекта
| Документ | Что внутри | Когда открывать |
|---|---|---|
| `transcripts/index.md` | Карта курса: по каждой лекции тема, краткое содержание, разделы с таймкодами (~20 КБ) | Первым, чтобы понять, в какой лекции тема |
| `transcripts/указатель.md` | Имена (≈270) и термины (≈170) → `Л<N> [чч:мм:сс] — в связи с чем` | Вопрос про конкретного философа, понятие, труд |
| `transcripts/оглавление/лекция N.md` | Подробно: разделы, термины с определениями лектора, персоналии, тезисы и примеры | Нужна суть лекции или формулировка лектора |
| `transcripts/лекция N.txt` | Полная расшифровка (Whisper). Абзацы по ~2 мин, каждый начинается с `[чч:мм:сс]` | Только нужный абзац по таймкоду, для цитаты или деталей |

## Порядок
1. `project_search` по ключевым словам или указатель/index → номер лекции + таймкод.
2. Нужны детали → `project_read` расшифровки, найти абзац с этой меткой (метки в оглавлениях совпадают с началом абзацев).
3. В ответе ссылаться на источник: «Л5, 00:13:42». Отделять позицию лектора от общих знаний.

## Особенности
- Whisper искажает имена и термины. В указателе и оглавлениях они исправлены, в расшифровках нет. Ищи по нескольким вариантам написания.
- Часть пояснений в указателе обрезана многоточием, таймкоды верные.
- Сырой вывод Whisper на ПК: `transcripts/лекция N.txt|.srt`. Пересборка индекса — см. `CLAUDE.md` в корне (скрипты в `scripts/`).
